# HDU 抢座 + 抢课

2026杭电图书馆预约抢座与教务选退课的一体化桌面工具（图形界面）。

## 环境要求

- Windows 推荐；需 **Python 3.8+**
- 校园网或学校 VPN（访问图书馆 / 教务系统）

## 安装与启动

```powershell
cd 项目目录
python -m pip install -r requirements.txt
python main.py
```

（Windows 若 `python` 指向错误版本，可用 `py -3.12 main.py` 等指定 3.8+。）

- 默认界面：左侧 **图书馆抢座**、**教务抢课**、**外观与参数**
- 经典双 Tab 界面：`python main.py --classic`

## 首次使用

1. 按向导填写学号；图书馆使用 **图书馆座位系统密码**（非统一认证密码）。
2. 若要用抢课，可在向导中勾选并填写 **教务 / 统一认证密码**；也可稍后在抢课页右上角单独登录。
3. 偏好（主题、字号等）保存在 `data/gui_prefs.json`。

## 图书馆抢座（简要）

| 入口 | 作用 |
|------|------|
| 我的方案 | 维护预约方案；支持添加 / 编辑 / 删除 |
| 立刻抢座 | 选日期与方案后手动开始重试 |
| 定时抢座 | 到放号时间自动抢（需保持程序运行） |
| 记录 | 查看历史结果 |

- 右上角：**登录 / 切换**（仅图书馆）、**使用手册**、**收纳小窗**（缩小窗口，定时任务可继续）
- 详细说明：程序内「使用手册」，或 `docs/图书馆抢座使用手册.txt`

## 教务抢课（简要）

| 入口 | 作用 |
|------|------|
| 课程 | 维护教学班列表（选课 / 退课） |
| 定时 / 蹲课 | 选「定时到点」或「蹲课」及时间参数 |
| 抢课操作 | 开始抢课、停止、保存配置 |

- 右上角：**登录 / 切换**（仅教务账号）、**使用手册**、**收纳小窗**
- 配置与账号保存在 `data/course/config.json`（勿上传到公开仓库）
- 详细说明：`docs/教务抢课使用手册.txt`

## 本地数据目录

| 路径 | 内容 |
|------|------|
| `data/seat/config.yaml` | 图书馆账号、方案、定时规则 |
| `data/seat/session.json` | 图书馆会话（自动生成） |
| `data/course/config.json` | 教务账号、课程列表、抢课参数 |
| `data/gui_prefs.json` | 界面主题与缩放 |
| `logs/` | 运行日志 |

首次运行若缺少配置，可参考 `data/course/config.example.json` 复制为 `config.json` 后修改。

## 侧栏「重新登录向导」

可随时重新设置图书馆账号，并可选一并配置抢课账号。
