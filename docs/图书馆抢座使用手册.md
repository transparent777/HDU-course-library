# 图书馆抢座使用手册

杭电图书馆预约（汇图系统）辅助工具。与 **教务抢课** 无关；抢课请用侧栏「教务抢课」。

---

## 1. 准备

1. 安装依赖：`python -m pip install -r requirements.txt`
2. 启动：`python main.py`
3. 使用 **学号 + 图书馆登录密码**（不是教务密码）完成登录。
4. 需能访问 `hdu.huitu.zhishulib.com`（校园网或 VPN）。

登录成功后程序会在后台拉取房间与座位列表，**首次可能需等待一两分钟** 再添加方案。

---

## 2. 界面说明

| 页签 | 作用 |
|------|------|
| **我的方案** | 配置要抢的馆、楼层、座位号、每天的开始时刻、使用时长 |
| **立刻抢座** | 选好日期后，从点击「开始抢座」起按间隔重试 |
| **定时抢座** | 配置放号规则，到点自动抢（须保持程序运行） |
| **记录** | 历次预约尝试结果 |

侧栏 **外观与参数** 可改字号、主题、抢座重试间隔与次数。

---

## 3. 方案（Plan）

方案 = 「抢什么」，**不包含具体哪一天**。

| 字段 | 说明 |
|------|------|
| 方案名称 | 自定义，定时任务里会引用 |
| 房间 / 楼层 | 从下拉列表选择 |
| 开始时间 | `HH:MM:SS`，如 `08:00:00` |
| 时长 | 小时数，开始时间 + 时长不得超过 22:00 |
| 座位号 | 多个用逗号分隔 |

**编辑**：在「我的方案」选中一行，点「编辑」或双击，可修改内容（方案名称不可改，避免定时任务引用失效）。

**删除**：选中后点「删除选中」。

---

## 4. 立刻抢座

适用：现在就要尝试预约（例如当天仍有空位、或测试配置）。

1. 在「我的方案」中 **选中** 要用的方案（不选则用全部）。
2. 打开「立刻抢座」，填写 **预约日期**（默认今天）。
3. 点 **开始抢座**；失败会按「外观与参数」中的间隔与最大重试次数继续。
4. 点 **停止** 可中断。

完整预约时间 = **预约日期** + 方案里的 **开始时刻**。

---

## 5. 定时抢座

适用：抢 **未来某一天** 的座位，并在馆方 **放号时刻** 自动提交。

### 5.1 放号规则（程序内置）

目标 **坐馆日** 为 X，则一般在 **X 往前 2 天的 20:00** 触发抢座（与常见馆方规则一致）。

列表中的 **下次放号** 列会显示计算结果。

### 5.2 添加规则

- **按日期添加**：指定一个或多个坐馆日（`YYYY-MM-DD`），并选择方案名称。
- **按每周添加**：勾选星期几「去坐馆」，并选择方案；每周重复，到点抢 **该周对应那天** 的座位。

可 **启用/停用**、**删除** 列表中的规则。

### 5.3 启动与停止

1. 添加至少一条 **启用** 的定时规则。
2. 点 **启动定时**（需已登录）。
3. 界面显示倒计时；到点自动抢，结果在「定时日志」与「记录」中查看。
4. 点 **停止定时** 可停止引擎。

### 5.4 程序要一直开着吗？

**是。** 定时逻辑运行在本机进程中：

- **关闭窗口并退出** → 定时停止。
- **收纳模式**（见下）→ 窗口缩小为条状，**定时可继续**。

---

## 6. 收纳模式（小窗）

把大界面收成屏幕角落的一条小窗，**定时任务可继续**（需已点「启动定时」）。

**入口（任选其一）：**

- 左侧导航 **「收纳小窗」**
- 抢座页右上角 **「收纳小窗」**（与「使用手册」同一行）

**使用说明：**

- 小窗显示倒计时或状态；点 **展开** 恢复大界面。
- 点 **退出** 会结束整个程序（定时随之停止）。
- 定时运行中点窗口 **关闭 (×)** 时，也可选 **收纳** 而不是退出。

**说明：** 这不是系统任务栏最小化，而是本程序自带的「条状小窗」模式。

## 8. 常见问题

**Q：定时到了没反应？**  
检查是否点了「启动定时」、是否仍登录、网络是否正常、规则是否为「启用」。

**Q：立刻抢和定时抢有什么区别？**  
立刻抢：从你点击起重试；日期由你填。定时抢：自动等到放号时刻；坐馆日由规则决定。

**Q：方案里改了时间，定时要改吗？**  
不用改定时规则；定时只绑定方案名称，具体时刻读方案内容。

**Q：楼层列表不全？**  
见项目说明或与开发者排查 API 返回结构；并非界面故意限制为 5 层。
