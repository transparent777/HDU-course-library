图书馆抢座使用手册

一、准备
  1. 命令行安装依赖后运行 main.py 启动程序。
  2. 用学号 + 图书馆登录密码登录。
  3. 需要能打开图书馆预约网站（校园网或 VPN）。
  4. 首次登录后会加载房间和座位，请等一两分钟再添加方案。

二、四个页签
  · 我的方案：设置馆、楼层、座位、每天几点开始、用几小时。
  · 立刻抢座：选日期后点「开始抢座」，从这一刻起按间隔重试。
  · 定时抢座：到放号时间自动抢，程序须保持运行。
  · 记录：查看历次预约结果。

  侧栏「外观与参数」可改字号、主题、重试间隔和次数。

三、方案说明
  方案只描述「抢哪个座位、几点开始、用多久」，不包含具体哪一天。
  · 添加：我的方案 → 添加方案。
  · 编辑：选中一行后点「编辑」或双击（名称不能改，以免定时任务找不到）。
  · 删除：选中后点「删除选中」。

四、立刻抢座
  1. 在「我的方案」可多选方案；不选则用全部。
  2. 在「立刻抢座」填写预约日期（默认今天）。
  3. 点「开始抢座」。若开始时刻早于当前时间，程序会提示，不会空抢。
  4. 点「停止」可中断。

  实际预约时间 = 预约日期 + 方案里的开始时刻。

五、定时抢座
  用于抢未来某天的座位。需要抢座时需要在抢座日前2天晚上8：00前进行设置。
  列表里「下次放号」一列是程序算出的触发时间。

  添加规则：
  · 按日期添加：指定坐馆日，并选择方案名称。
  · 按每周添加：勾选星期几去坐馆，并选择方案（每周重复）。

  使用步骤：
  1. 添加至少一条「启用」的规则。
  2. 点「启动定时」（需已登录）。
  3. 看倒计时；到点自动抢，结果在「定时日志」和「记录」里。
  4. 点「停止定时」可停止。

  注意：关掉整个程序，定时就停了。想缩小窗口请用「收纳小窗」。

六、收纳小窗
  把大界面收成屏幕角落一条小窗，定时可继续（需已启动定时）。
  · 点「展开」恢复大界面。
  · 点窗口右上角关闭可退出程序（定时会停）。
  · 定时运行中点关闭时，也可选收纳而不是退出。


七、配置文件（一般不用手改）
  data/seat/config.yaml — 账号、方案、定时
  data/seat/session.json — 登录缓存
  data/gui_prefs.json — 界面偏好

八、经典界面（可选）
  默认是侧栏大界面（python main.py）。
  · python main.py --classic — 旧版 tk 多页签，功能与上文一致。
  · python main.py --daemon — 无菜单，直接按 config.yaml 启动定时（须已配好方案与定时）。
